\abstract{Children with juvenile dermatomyositis perform Childhood Myositis Assessment Scale (CMAS) exercises under hospital supervision. Which is burdensome for families. This feasibility study investigated whether the Reachy Mini robot can serve as an engaging platform for home activity monitoring under its computational constraints. Using an iterative Design Science Research inspired approach. A prototype was developed with a shared software core running identical recognition code in simulation and on the robot. The pipeline combines MoveNet Lightning pose estimation, torso-normalised temporal features over sliding windows, and NumPy-exported random forests, with real-time expressive feedback through antennas and person tracking. Person detection was improved from 52 procent to 72 procent of frames by cropping around the previous pose. The prototype recognises four CMAS items without scoring them. The conclusion is that CPU only activity monitoring with expressive feedback is technically feasible, but clinical validation and user studies remain necessary before actual home use.}
