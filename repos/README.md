# Reachy Mini – Repositories

This folder contains the source-code archives used during the Reachy Mini model benchmarking and GPU experiments:

- `benchmarking_BlazePose_MoViNet_TSM_ViTPose.zip` – initial benchmarking of the four models.
- `ReachyMini_BlazePose_LiteRT_WebGPU_ARM64.zip` – native BlazePose GPU implementation attempt using LiteRT and WebGPU.
- `ReachyMini_GPU_Experiments_MoveNet_WebGPU_Vulkan.zip` – MoveNet WebGPU and alternative Vulkan experiments.

The GPU implementations were not successfully completed. Further details about the approaches, results and encountered issues are provided in the **Extended Abstract and its accompanying appendices**.
